## 🌟 Project Overview
The **School of Science, Ile-Ife** website was rebuilt from the ground up to provide a premium digital experience for students, parents, and faculty. Moving away from standard static pages, we implemented a custom SPA (Single Page Application) architecture that mimics the behavior of modern frameworks like React.js but with zero dependencies and lightning-fast load times.

## ✨ Key Features
- **Fluid Navigation**: No page reloads. Transitions between sections (About, Academics, Admissions, etc.) are handled instantly with a sleek "fade-and-slide" effect.
- **Sleek Animations**: 
    - **Scroll-Reveal Engine**: Elements elegantly slide into view as you explore.
    - **Interactive Hero**: A subtle mouse-parallax effect in the header for a premium feel.
    - **Dynamic Counters**: Watch the school's statistics grow as you scroll.
- **Robust Pages**: Each section is designed as a deep-dive "view," providing detailed information on departments, admission procedures, and campus life.
- **Live Google Maps**: A fully interactive, lazy-loaded map showing the school's exact location.
- **Modern Responsive Design**: Fully optimized for smartphones, tablets, and desktops with a custom-engineered mobile navigation menu.

## 🛠 Tech Stack
- **HTML5**: Semantic structure for better SEO and accessibility.
- **Vanilla CSS3**: Modern layouts using CSS Grid and Flexbox with custom properties (Variables).

- **Font Awesome**: Professional iconography.
- **Inter Font Family**: Clean, modern typography for academic clarity.

## 🏗 Architecture (For Developers)
This project follows a modular "App Shell" pattern:

- **`index.html`**: The main entry point and persistent shell (Header/Footer).
- **`js/router.js`**: A custom hash-based router that manages navigation and view swapping.
- **`js/components.js`**: A centralized library of view templates.
- **`js/main.js`**: The orchestrator that initializes the app, manages the global animation engine, and handles persistent UI logic.
- **`/assets/`**: Organized directory for optimized school photography and logos.

1. **Clone the repository**:

2. **Open `index.html`**: Simply open the `index.html` file in any modern web browser.
3. **Optional (Devs)**: Use a local server (like VS Code's "Live Server" or `npx serve`) for the best experience with the SPA transitions.
